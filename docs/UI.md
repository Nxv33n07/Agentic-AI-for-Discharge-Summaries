# Dscribe Web UI

A production-grade frontend for the Dscribe agentic AI, built with the
[ui-ux-pro-max skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill),
Next.js 14 (App Router), Tailwind CSS, and Motion (the new Framer Motion).

## Why this UI

The take-home assignment evaluates a clinical agent's **judgment under
uncertainty** — so the UI must surface that uncertainty clearly, never hide
it. Every design choice maps back to a clinical-safety requirement:

| UI element | Maps to assignment requirement |
|---|---|
| `[MISSING]` / `[PENDING]` / `[CONFLICT]` chips in the draft viewer | No fabrication, honest uncertainty |
| Escalation panel on the trace page | "Surface and escalate, never bury" |
| Hard iteration cap badge | Control (hard cap on agent loop) |
| Three-layer guardrail explainer card | No-fabrication guardrail |
| Live API health pill in the topbar | Robust failure handling (no silent crashes) |
| Confetti on successful draft | Visible success signal for the clinician |
| Learning-loop guardrails panel | "Don't degrade Part 1 safety" |

## Tech stack

- **Next.js 14.2** (App Router, RSC where possible, `"use client"` for interactive surfaces)
- **React 18** + **TypeScript 5**
- **Tailwind CSS 3.4** with CSS variables for theming tokens
- **Motion 12** (the new framer-motion) for page transitions, stagger reveals, animated counters, progress arcs
- **lucide-react** for icons (no emoji-as-icons, per the design rules)
- **class-variance-authority** for variant-driven component APIs
- **shadcn/ui**-style components in `components/ui/`
- **21st.dev-style** primitives: `SpotlightCard`, `AnimatedCounter`, `ProgressArc`, `GlowPulse`, `Marquee`, `Confetti`

## Design system

Generated by the skill and persisted to `design-system/dscribe/MASTER.md`.
The palette and tokens are wired into `app/globals.css` and `tailwind.config.ts`.

| Token | Value | Role |
|---|---|---|
| `--color-primary` | `#0891B2` | Trust, links, primary CTA |
| `--color-secondary` | `#22D3EE` | Soft accent, charts |
| `--color-cta` | `#059669` | Health-green for "Run Agent" |
| `--color-background` | `#ECFEFF` | Calm cyan-tinted background |
| `--color-text` | `#164E63` | Body text (4.5:1+ on background) |
| Headings | Fira Code | Dashboard / data vibe |
| Body | Fira Sans | Readable at 16px+ |

Style keywords: **Accessible & Ethical** — high contrast, large text,
keyboard navigation, screen-reader friendly, WCAG AAA.

## Page map

| Route | File | Purpose |
|---|---|---|
| `/` | `app/(pages)/dashboard/page.tsx` | Hero, stats, feature cards, patient list, requirement checklist |
| `/patients` | `app/(pages)/patients/page.tsx` | Run the agent (selector, learning toggle, confetti on success) |
| `/drafts` | `app/(pages)/drafts/page.tsx` | List of generated drafts |
| `/drafts/[patientId]` | `app/(pages)/drafts/[patientId]/page.tsx` | Rendered markdown draft with status chips, copy/download |
| `/trace` | `app/(pages)/trace/page.tsx` | Patient list for the trace viewer |
| `/trace/[patientId]` | `app/(pages)/trace/[patientId]/page.tsx` | Step-by-step ReAct trace with escalations panel |
| `/learning` | `app/(pages)/learning/page.tsx` | Part 2 learning loop: NED curve, learned rules, safety guardrails |

## Running

```bash
# Terminal 1 — FastAPI backend
python -m uvicorn src.api.main:app --reload --port 8000

# Terminal 2 — Next.js web UI
cd ui/web
npm install              # first time only
cp .env.example .env.local
npm run dev              # → http://localhost:3000
```

The UI talks to `NEXT_PUBLIC_API_URL` (default `http://localhost:8000`).

## Accessibility & motion

All interactive elements meet the ui-ux-pro-max pre-delivery checklist:

- **Focus rings** — every focusable element has a visible 2px ring.
- **Touch targets** — buttons and links are ≥ 44×44 px.
- **Contrast** — body text on `background` measures
